# Weather App

A lightweight, responsive web application built with vanilla JavaScript, HTML5, and CSS3 that fetches and displays real-time weather information.

## Features

- **Real-Time Weather Updates:** Displays current temperature, humidity, wind speed, and atmospheric conditions.
- **Location Search:** Query weather data by city name.
- **Responsive Layout:** Adaptive user interface designed for mobile, tablet, and desktop viewports.
- **Dynamic DOM Manipulation:** Efficient state rendering directly via ES6 JavaScript without external heavy framework overhead.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **API Integration:** REST API (OpenWeatherMap / Weather API)
